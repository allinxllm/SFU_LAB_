1. История создания

Java — объектно-ориентированный язык программирования, разработанный компанией Sun Microsystems в 1995 году. Изначально проект носил название Oak и создавался для программирования бытовых электронных устройств.

Руководителем проекта был канадский инженер Джеймс Гослинг. В 1995 году язык был переименован в Java и официально представлен публике. Название было выбрано в честь сорта кофе с острова Ява.

Ключевой особенностью Java стал принцип «Write Once, Run Anywhere» — «напиши один раз, запускай где угодно». Это стало возможным благодаря JVM (Java Virtual Machine) — виртуальной машине, которая исполняет байт-код независимо от операционной системы.

2. Краткий обзор языка

Java относится к классу компилируемых языков. Исходный код компилируется в байт-код, который затем исполняется виртуальной машиной JVM. Это обеспечивает переносимость программ между различными платформами.

Язык поддерживает все основные принципы объектно-ориентированного программирования:

  1. Инкапсуляция — сокрытие внутренней реализации объекта.
  2. Наследование — создание новых классов на основе существующих.
  3. Полиморфизм — способность объектов иметь различную реализацию.

Java строго типизирован: каждая переменная должна быть объявлена с указанием типа данных. Основные типы данных:

  • int — целые числа
  • double — числа с плавающей точкой
  • boolean — логический тип (true/false)
  • char — символы Unicode
  • String — строки (ссылочный тип)

Популярные области применения Java:

  • Серверные приложения и микросервисы
  • Android-приложения
  • Банковские и корпоративные системы
  • Big Data (Hadoop, Spark)

3. Примеры кода

Программа «Hello, World!»

public class HelloWorld {
    public static void main(String[] args) {
        // Вывод строки на консоль
        System.out.println("Hello, World!");
    }
}

Условные операторы

public class Example {
    public static void main(String[] args) {
        int number = 42;
        if (number > 0) {
            System.out.println("Положительное");
        } else {
            System.out.println("Отрицательное");
        }
    }
}

Цикл и массивы

public class ArrayDemo {
    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40};
        int sum = 0;
        for (int i = 0; i < numbers.length; i++) {
            sum += numbers[i];
        }
        System.out.println("Сумма: " + sum);
    }
}

Класс и объект

public class Student {
    private String name;
    private int age;

    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void introduce() {
        System.out.println("Меня зовут " + name);
    }
}
